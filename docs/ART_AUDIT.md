# Look-vs-original audit (wiki art compared with the procedural models)

Method: each creature's idle pose rendered with tools/preview-style software renderer next to the wiki image (slaythespire.wiki.gg `File:*.png`; images are NOT stored in the repo).
Finding: most creatures were modelled from descriptions without seeing the art, so silhouettes/colours often differ. Lagavulin was rebuilt after this audit (pale egg shell with slits, diamond + X eye, orange spiny legs).
